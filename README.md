## Overview

A Node.js TypeScript program (`main.ts`) that writes a single-line, <=200-character comedy review of the mailman from a dog's perspective to `/output/entry.txt` (or a custom path/directory via CLI flags or `MAKEFUN_OUTPUT_DIR`).

## Usage

```bash
node main.ts
```

Supported output overrides:

- `--out <path>` / `--output <path>` / `-o <path>`
- `--out-dir <dir>`
- `MAKEFUN_OUTPUT_DIR=<dir>`
